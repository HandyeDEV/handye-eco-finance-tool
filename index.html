5. Planilha de freelancer: rendimentos por dia

Anote o que você recebeu em cada dia. O app soma o mês e mostra sua média.

DataCliente / serviçoValor

O CSV abre no Excel, Google Planilhas e LibreOffice. Para importar, use colunas na ordem Data, Cliente/serviço e Valor (datas como 31/12/2026 ou 2026-12-31). Importar soma as linhas às que você já tem.

6. Seus dados: exportar e importar

Tudo fica salvo só neste aparelho. Baixe um arquivo para guardar uma cópia ou para levar seus dados do computador para o celular (e o contrário).

O arquivo .json inclui salário, gastos, meta e a planilha de freelancer. Importar substitui os dados que estão aqui agora. O arquivo não é enviado a nenhum servidor: é lido só no seu navegador.

Os cálculos de INSS e IR são estimativas (tabelas no início do arquivo, fáceis de atualizar). Não é consultoria financeira. Os dados ficam só neste aparelho; use "Exportar" para guardar uma cópia.
